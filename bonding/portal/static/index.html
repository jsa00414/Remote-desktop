How traffic is routed

Internet — visitors hit the VPS public IP, then WireGuard to a LAN device. Use this for Windows RDP, websites, and most remote access.

Router — only for the Flint WAN or WireGuard into the router. Not required if the VPS already forwards the port.

Bonding — combines the Flint’s internet links (WAN + USB/LTE/phone tether) into one pipe through the VPS. No Speedify account.

Bonding

Speedify-style channel bonding. Every live WAN on the Flint is combined into one encrypted tunnel. Wi-Fi devices share that pipe. While connected, internet exits from the VPS IP. Disconnect returns Wi-Fi to the home ISP immediately.

Connect waits until the tunnel can ping, then steers LAN. The VPS answers on UDP 8443, 51820, and 4410 — the Flint uses whichever port the cloud firewall allows. If IONOS blocks 4410, 8443 still works. Plug in a second link (USB LTE / phone tether) to aggregate.
